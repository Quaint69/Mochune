# Reference theme

Open `skin.json` for the usable whole-mode example, or `format-reference.json`
for exported component keys and all paint fields/states.

Both use the same tiny original RGBA PNGs generated for this repository:
`frame.png` (12×12, four-pixel nine-slice) and `play.png` (24×24, transparent
triangular play symbol). They may be edited and redistributed with the theme
examples. Read `../AUTHORING.md` for inheritance, ownership and limits.
